Holonet Support

Holonet needs to be enabled in Safari before it can change how a webpage looks.

Set up the extension

  1. Open Settings and choose Safari. On newer iOS versions, Safari is under Apps.
  2. Choose Extensions, select Holonet, and turn on Allow Extension.
  3. Choose which websites Holonet can access. Safari’s website controls can be changed later in Settings.
  4. In Safari, open the Page menu, select Holonet, turn it on, and choose Standard or Digraphs.

Contact support

If you have a question or run into a problem, email zacharyfarnes@gmail.com. Please include your device model and iOS version if you are asking about a technical issue. Avoid including private webpage content.
